- HWPDocument class:
  Creates and manipulates Hangul Word Processor (HWP) documents with Korean language support.
  
  Usage Example:
  ```python
  hwp = HWPDocument()
  
  # Document structure and formatting
  hwp.add_heading("제목", level=1)    # Adds heading with specified level (1-7)
  hwp.add_paragraph("일반 텍스트")     # Adds paragraph with default styling
  hwp.add_text_content("""
      여러 줄의 텍스트를
      자동으로 서식에 맞게 처리
  """)                              # Adds multi-line text with auto-formatting
  
  # Tables
  data = [
      ["이름", "나이", "직업"],     # Header row
      ["홍길동", "30", "개발자"],   # Data rows
      ["김철수", "25", "디자이너"]
  ]
  hwp.add_table(
      data=data,
      header=["이름", "나이", "직업"],  # Optional: header row
      page_break=False                  # Optional: start new page before table
  )
  
  # Images
  # 1. 파일 경로로 이미지 추가
  hwp.add_image("image.jpg")           # Adds image from file path with auto-sizing
  
  # 2. matplotlib 플롯 이미지 추가
  import matplotlib.pyplot as plt
  
  plt.figure()
  plt.plot([1, 2, 3], [1, 2, 3])
  plt.title("Sample Plot")
  temp_image_path = "temp_plot.png"
  plt.savefig(temp_image_path)
  plt.close()
  hwp.add_image(temp_image_path)
  
  # 3. PIL 이미지 객체로 추가
  from PIL import Image
  img = Image.open("image.jpg")
  hwp.add_image(img)
  
  # 4. 바이트 데이터로 이미지 추가
  with open("image.jpg", "rb") as f:
      image_bytes = f.read()
  hwp.add_image(image_bytes)
  
  # Page control
  hwp.add_page_break()                 # Starts a new page
  
  # Save the final document
  hwp.save("output.hwp")
  ```

  Notes for HWP documents:
  - Supports Korean text and formatting automatically
  - Handles different Korean encodings
  - Maintains HWP-specific styling and layout
  - Tables support merged cells and custom styling
  - Images are automatically scaled and positioned
