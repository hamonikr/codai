# 주요 기능 상세 설명

## 코드 생성 (`codai code`)

![코드 생성](codai-code.png)

코드 생성 기능은 자연어 설명을 바탕으로 실행 가능한 코드를 생성합니다.

### 주요 특징
- 컨텍스트 인식 코드 생성
- 다중 언어 지원
- 자동 임포트 및 의존성 관리
- 실시간 코드 검증

### 사용 예시
```bash
codai code "REST API 서버 생성" --lang python
codai code "정규식으로 이메일 검증" --lang rust
```

## 채팅 모드 (`codai chat`)

![채팅 모드](codai-chat.png)

개발 관련 질문에 대한 즉각적인 답변을 제공합니다.

### 주요 특징
- 개발 컨텍스트 인식
- 코드 스니펫 포함
- 마크다운 렌더링
- 대화 기록 유지

## 작업 실행 (`codai task`)

![작업 실행](codai-task.png)

복잡한 개발 작업을 자동화하고 실행합니다.

### 주요 특징
- 작업 분할 및 계획
- 진행 상황 추적
- 오류 처리 및 복구
- 결과 검증

## 코드 리뷰

![코드 리뷰](codai-review.png)

코드 품질 향상을 위한 자동화된 리뷰를 제공합니다.

### 주요 특징
- 보안 취약점 검사
- 코드 스타일 검증
- 성능 최적화 제안
- 버그 가능성 분석

## 다국어 지원

![다국어 지원](codai-i18n.png)

다양한 언어로 된 개발 문서 및 코드 주석을 처리합니다.

### 주요 특징
- 문서 번역
- 코드 주석 번역
- 로컬라이제이션 지원
- 다국어 에러 메시지

## 통계 및 분석

![통계 및 분석](codai-statistics.png)

AI 사용량 및 비용을 추적하고 분석합니다.

### 주요 특징
- 토큰 사용량 추적
- 비용 분석
- 사용 패턴 분석
- 최적화 제안
